## Quick Start

### Local Development

1. Navigate to the project folder:
```bash
cd C:\Users\USER\CascadeProjects\TutorNest
```

2. Install dependencies (optional, for local server):
```bash
npm install
```

3. Start local server:
```bash
npm start
```

Or simply open `index.html` in your browser.

## Deployment Options

### Option 1: Netlify (Recommended - FREE)

1. Go to [Netlify](https://www.netlify.com)
2. Sign up/Login with GitHub
3. Click "Add new site" → "Deploy manually"
4. Drag and drop the TutorNest folder
5. Your site will be live in seconds!

**Custom Domain:** You can add a custom domain in Netlify settings

### Option 2: Vercel

1. Install Vercel CLI:
```bash
npm i -g vercel
```

2. Deploy:
```bash
vercel
```

3. Follow the prompts to deploy

### Option 3: GitHub Pages

1. Create a GitHub repository
2. Push the code:
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin YOUR_REPO_URL
git push -u origin main
```

3. Go to Settings → Pages → Deploy from main branch
4. Your site will be live at: `https://yourusername.github.io/tutornest`

### Option 4: Firebase Hosting

1. Install Firebase CLI:
```bash
npm install -g firebase-tools
```

2. Initialize and deploy:
```bash
firebase init hosting
firebase deploy
```
