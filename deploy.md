# 🚀 Deploy TutorNest in 2 Minutes!

## Option 1: Netlify (Easiest - No Code Required!)

1. **Open your browser** and go to: https://app.netlify.com/drop

2. **Open File Explorer** to: `C:\Users\USER\CascadeProjects\TutorNest`

3. **Drag the entire TutorNest folder** onto the Netlify Drop page

4. **Your site is LIVE!** You'll get a URL like: `https://amazing-tutor-123.netlify.app`

5. **Optional**: Create a free Netlify account to:
   - Rename to: `https://tutornest.netlify.app`
   - Add custom domain
   - View analytics

## Option 2: Quick Terminal Deploy

```bash
# If you have npm installed:
cd C:\Users\USER\CascadeProjects\TutorNest
npx netlify-cli deploy --dir . --prod

# Or use Vercel:
npx vercel --prod
```
