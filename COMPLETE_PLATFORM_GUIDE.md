## 🚀 **How to Deploy & Run**

### **Quick Start (Local)**
```bash
# Frontend
cd C:\Users\USER\CascadeProjects\TutorNest
open index.html

# Backend
cd backend
npm install
npm run seed-tutors  # Populate with 50+ tutors
npm run seed-students # Populate with students
npm start            # Start API server
```

### **Production Deployment**

#### **Frontend (Netlify)**
1. Push to GitHub
2. Connect to Netlify
3. Auto-deploy on push
4. Custom domain: tutornest.com

#### **Backend (Heroku/Render)**
1. Deploy Node.js app
2. Set environment variables
3. Connect MongoDB Atlas
4. Enable WebSocket

#### **Database (MongoDB Atlas)**
1. Create cluster (Free tier)
2. Whitelist IPs
3. Get connection string
4. 50+ tutors pre-loaded

## 📞 **API Endpoints (Connected & Working)**

### **Authentication:**
- `POST /api/auth/register` - Register student/tutor/parent
- `POST /api/auth/login` - Universal login
- `POST /api/auth/verify-email` - Email verification
- `POST /api/auth/reset-password` - Password reset

### **Tutors:**
- `GET /api/tutors/search` - Search with 15+ filters
- `GET /api/tutors/:id` - Get tutor profile
- `POST /api/tutors/apply` - Apply to teach
- `GET /api/tutors/verification/status` - Check vetting
- `PUT /api/tutors/profile` - Update profile
- `GET /api/tutors/dashboard/stats` - Earnings & analytics

### **Sessions:**
- `POST /api/sessions/book` - Book session
- `POST /api/sessions/instant` - Start instant class
- `GET /api/sessions/upcoming` - Get schedule
- `POST /api/sessions/:id/join` - Join video call
- `POST /api/sessions/:id/complete` - End & pay

### **Students:**
- `GET /api/students/dashboard` - Learning center
- `GET /api/students/progress` - Track progress
- `POST /api/students/homework` - Submit questions
- `GET /api/students/resources` - Study materials
